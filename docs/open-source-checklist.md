# Open-source publication checklist

The code is intentionally local until these gates are completed:

- [ ] Complete organization legal and security review.
- [ ] Select and add an approved open-source license.
- [ ] Confirm rights to every example, prompt, and fixture.
- [ ] Run repository-wide secret and private-host scans.
- [ ] Replace pre-release paper metadata with the final citation.
- [ ] Add public project, paper, dataset, and issue-tracker URLs.
- [ ] Confirm model-provider terms permit the documented workflow.
- [ ] Re-run tests on supported Python versions.
- [ ] Review generated artifacts and verify they remain ignored.
- [ ] Create the public remote only after explicit authorization.
